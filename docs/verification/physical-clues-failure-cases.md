# Physical clues: failure cases written before implementation

7 October 2026. Tyler authorized all recommended work in the P4 thread. Files selected for a private experiment; production promotion and human acceptance are not claimed.

- Separate clients or reconnects invent different trails; old evidence survives objective relocation, or player respawn deletes shared evidence.
- Ground marks appear in mid-air, water, walls, on the wrong storey, or across a teleport.
- A stationary objective loses every clue; old evidence silently becomes fresh; handoff deletes truthful history.
- Unbounded history, per-frame database writes, oversized packets, duplicate ids or non-finite positions.
- Hidden clues consume the visible budget; no readable paper silhouette on mobile, Blackout or low quality.
- Paper corners, orientation, screen UI or old beacons directly point to the case; death recap retains an arrow.
- Bots follow a live hidden loose case, global pings, undisclosed carrier identity, or precise clue age/order; Jev learns more than the code mind or player.
- Bots repeatedly return to one inspected clue instead of searching or fighting.
- Case/trap/weapon rules, mode targets, movement, packed aggregates, or room hibernation regress.

Proof: bounded physics/authority → snapshot → compact wire → two receivers/restore, actual bot perception/goals, and a repeatable rendered scene. These integration checks cannot establish human understanding. Private human Excessive Force comparison remains the acceptance gate for search enjoyment.
