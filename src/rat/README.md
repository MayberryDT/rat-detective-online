# Rat appearance and acting

Start at [RatModel.ts](RatModel.ts) for body construction, [RatAnimator.ts](RatAnimator.ts) for acting, and [WeaponModel.ts](WeaponModel.ts) for held weapon art. These are view code. Physical movement belongs to [shared/rat](../shared/rat/ratBody.ts); the live entity and its lifecycle belong to [RatEntity](../entities/RatEntity.ts). General rendering helpers remain in [utils](../utils/README.md).
